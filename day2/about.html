About QuickNotes

QuickNotes is a simple web app for writing down short notes as soon as you think of them. It keeps your ideas in one place so you can find them again and never lose them.

How to use QuickNotes

  1. Open the Home page.
  2. Type your note in the "New note" box.
  3. Click "Add Note" or press Enter.
  4. Read your saved notes in the "Your notes" list.

Features

  • Add a note in seconds
  • See all your notes in one list
  • See how many notes you have
  • Works on phones and computers

Keyboard shortcuts

Shortcut Action
Enter Add the note
Tab Move to the next field
Ctrl + S Save the file in VS Code
